## Phase Details

### Phase 1: Existing ORION Infrastructure
- **Components**: Keycloak, OPA, TITAN, PHOENIX
- **Measurable**: System runs stably
- **Resource**: Solo developer

### Phase 2: AURA Intelligence Core
- **Components**: AURA Orchestration, AURA Memory
- **Dependencies**: Phase 1
- **Measurable**: Passes baseline reasoning eval
- **Resource**: Solo developer + Local GPU

### Phase 3: OMNIS World Model
- **Components**: Graph DB, Causal schemas
- **Dependencies**: Phase 2
- **Measurable**: Can represent drought causal chain
- **Resource**: Solo developer

### Phase 4: NEXUS Multi-Agent Fabric
- **Components**: Agent Registry, Dispute Resolution
- **Dependencies**: Phase 3
- **Measurable**: 3 agents solve cross-domain problem
- **Resource**: Solo developer

### Phase 5: FORGE Scientific Engine
- **Components**: Simulation sandboxes
- **Dependencies**: Phase 4
- **Measurable**: Generates and tests 1 valid hypothesis
- **Resource**: Solo developer

### Phase 6: ASCEND Long-Horizon Planning
- **Components**: Objective solver, Error tracking
- **Dependencies**: Phase 4
- **Measurable**: 10-year plan, adapts to 1 disruption
- **Resource**: Solo developer

### Phase 7: Civilization Simulation
- **Components**: MIRROR extension (10M population)
- **Dependencies**: Phase 3 + Phase 6
- **Measurable**: Runs 20 simulated years stably
- **Resource**: Team / Cloud Compute

### Phase 8: Controlled Real-World Interfaces
- **Components**: VEIL Governance, IoT bindings
- **Dependencies**: Phase 1 + Phase 7
- **Measurable**: Passes strict security audit
- **Resource**: Team

### Phase 9: ACI Benchmark
- **Components**: Evaluation harness (ACI-001)
- **Dependencies**: Phase 7
- **Measurable**: Score > 50/100
- **Resource**: Solo / Team

### Phase 10: Independent Evaluation
- **Components**: Documentation, reproducible environment
- **Dependencies**: Phase 9
- **Measurable**: External confirmation
- **Resource**: External Auditors
