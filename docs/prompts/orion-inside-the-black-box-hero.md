## SOURCING AND ACCURACY NOTE

Kept inside the file so the render can never be mistaken for a literal
technical claim:

- **The `896 → 256 → 128 → 4096` pipeline is the client/operator's
  specification for the hero visual.** It does not exist verbatim in the
  codebase; it is rendered as a labeled visualization of the network's
  architecture, with nodes representing layer groups, not neurons.
- **The model ORION actually trains and ships is Qwen2.5-0.5B** — 24
  transformer layers, hidden 896, feed-forward 4864, 151,936-token vocab,
  LoRA (r8/α16) on q/v projections → GGUF → Ollama (see
  `scripts/training/orion_train.py`, `orion_dpo.py`,
  `convert_hf_to_gguf.py`). 896 is the one number in the brief that matches
  reality (the hidden dimension).
- **NECTAR** is the only bio-computational instrument with measured results:
  138,639 neurons / 15.09M modeled edges / 99.76% precision / 93.08% recall /
  1.756× odor factor / 66.9 ms (from `data/nectar/results`).
- Labels like BRIAN2/LIF, mushroom-body learning, FORGE, OMNIS, CHRONOS,
  MIRROR TWIN, ASCEND, AEGIS, SHIELD, OPA, AURA, NECTAR all correspond to real
  ORION modules (`docs/`, `scripts/`).
