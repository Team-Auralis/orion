ORION -> AURA -> OMNIS -> NEXUS -> FORGE -> ASCEND -> CIVILIZATION SIMULATION -> GOVERNED REAL-WORLD INTERACTION -> ACI BENCHMARK -> INDEPENDENT VALIDATION

## Core Architecture

ORION proposes ACI as a research and engineering framework for studying civilization-scale machine intelligence. The system does NOT claim to be ACI, AGI, or ASI. It is an experimental framework to make such claims testable.

### Core Modules

- **AURA**: The multimodal intelligence and reasoning core.
- **OMNIS**: The continuously updateable civilization world model (Entities, Relationships, Causality).
- **NEXUS**: The multi-agent intelligence fabric for coordination, dispute resolution, and aggregation.
- **FORGE**: The scientific discovery and hypothesis generation engine.
- **ASCEND**: The long-horizon planner (days to decades) handling uncertainty and replanning.
- **VEIL / SHIELD / OPA**: The strict governance and security layer controlling all real-world interactions.
